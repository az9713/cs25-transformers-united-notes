Numerical laboratory: attention, representations and distributed algebra

A next-token predictor must not use future input positions when computing the current prediction. A causal attention mask permits keys at the query's position and earlier. This finite experiment makes the consequence visible: changing the third value cannot change the first two attention outputs when the causal mask is enabled.

The three queries are all 1. The keys are 0, log(3) and log(2), so their unmasked softmax weights are 1/6, 3/6 and 2/6. The first two values are 0 and 6; you choose the third. The query and key width is one, so scaling by the square root of that width leaves these logits unchanged. Values and outputs are dimensionless teaching quantities.

Check the calculation

At query position 2, the permitted exponentials are 1 and 3. Their weights are 1/4 and 3/4; the output is 0/4 + 18/4 = 4.5. Replace the third value with 1200: that output stays 4.5 with the mask enabled. Disable the mask and the output becomes (0 + 18 + 2400)/6 = 403. At query position 3, all three keys are permitted, so both mask settings agree.

These queries and keys are fixed. The experiment checks the masking operation, not model training, linguistic competence or factual reliability. An entire causal model must also keep every other information path consistent with its causal assumptions.
